

# Clone Jobs and Calendar Appointments

## Overview
Add a "Clone Job" button to the Job Detail page that duplicates the job record and optionally its calendar appointments, making it easy to create similar jobs without re-entering all the details.

## What You'll See

- A new **"Clone Job"** button in the Job Detail header (next to Edit Job)
- Clicking it opens a confirmation dialog asking whether to also clone the calendar appointments
- The cloned job opens automatically so you can adjust any details

## How It Works

1. **Clone the Job**: Copies all job metadata (title, type, customer, location, priority, notes, quoted amount, dates) into a new record. The title gets " (Copy)" appended. The new job starts at the first workflow stage with a fresh job number (auto-generated by the database).

2. **Clone Appointments** (optional): If selected, all calendar appointments from the original job are duplicated onto the new job -- same times, teams, attendees, and notes. Google Calendar sync is NOT copied (the cloned appointments start un-synced so you can adjust times before syncing).

3. **Navigate**: After cloning, you're taken to the new job's detail page.

## Files to Change

### 1. `src/pages/admin/JobDetail.tsx`
- Import `Copy` icon from lucide-react and `AlertDialog` components
- Add `cloneJobMutation` using `useMutation`:
  - Reads current job data
  - Inserts a new `crm_jobs` row with copied fields, initial stage, title + " (Copy)"
  - If "include appointments" is checked, fetches `crm_job_appointments` for the original job and bulk-inserts them with the new job ID (without `google_calendar_event_id`)
  - On success, navigates to `/admin/jobs/{newJobId}`
- Add a "Clone Job" button in the header button group
- Add a small AlertDialog for clone confirmation with a checkbox for "Include calendar appointments"

### 2. No other files need changes
The clone logic is self-contained on the Job Detail page using existing database tables and auto-generated job numbers.

## Technical Details

### Clone mutation pseudocode:

```text
1. Read current job fields (title, job_type_id, customer_id, location_id, 
   priority, scheduled_date, scheduled_end_date, quoted_amount, 
   internal_notes, customer_notes)
2. Get initial stage for job type
3. INSERT into crm_jobs with:
   - All copied fields
   - title: original + " (Copy)"
   - current_stage_id: first stage
   - payment_status: "no_charge_yet"
   - No workedge_project_id (starts unlinked)
4. If includeAppointments:
   - SELECT all crm_job_appointments WHERE job_id = originalId
   - For each: INSERT with new job_id, same times/team/attendees/notes
     but google_calendar_event_id = null
5. Navigate to new job
```

### What is NOT cloned:
- Job number (auto-generated fresh)
- Stage history (starts clean)
- Team assignments (can be re-assigned)
- WorkEdge link (starts unlinked)
- Google Calendar event IDs (appointments start un-synced)
- Actual start/end times
- Payment status (resets to "no_charge_yet")
